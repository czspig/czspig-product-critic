# 导航与草稿体验验收

本轮使用 Codex 内置浏览器的 Playwright API 实际点击验证。前端运行于 http://127.0.0.1:5174，代理后端 http://127.0.0.1:8081。AI 模式为 Mock，截图与数据只证明导航、状态和版本关联，不代表真实模型输出质量。

## 修改

- 报告导航使用明确的目的地；来源保存在路由 query 中，仅接受当前项目版本对比、工作台和历史分页路径，其他来源回退当前项目工作台。
- 项目名称来自首版输入摘要的简短片段，在报告、历史、版本页、工作台和草稿页保持一致。缺失时使用“产品想法项目”，不使用整段 Idea 或数据库 ID 作为标题。
- 报告页仅突出“基于此版本继续优化”，说明进入草稿、提交才创建报告。原复制、导出、任务包与体检卡入口收进“更多操作”。
- 迭代编辑使用独立 /drafts/:sourceId 地址。草稿按匿名会话、项目与来源报告隔离，保存输入、模式、毒舌程度，写入并读回确认后才显示“已保存”。失败显示备份与丢失风险提示。
- 生成成功切换为独立结果状态，输入表单隐藏，提供完整报告、工作台、继续优化入口。新建评审不继承迭代上下文。
- 历史保留分页和列表，分别展示报告版本、项目最新版本，并提供“查看报告”“查看项目”。
- 实测修复窄窗口体检卡预览遮挡底部按钮的问题。

## 检查与限制

- npm run build：TypeScript 与 Vite 构建通过。
- node --test tests/experience.test.cjs：3 项通过，覆盖站外/跨项目来源回退、项目/来源草稿隔离、保存失败与损坏草稿。
- 存储失败通过自动测试模拟，浏览器实测采用正常存储环境，未改变浏览器安全或隐私设置。
- 下载按钮与成功触发反馈已实测，但内置浏览器下载事件等待超时，无法确认文件最终落盘；不把开始下载描述为完成下载。
- 草稿保存在当前浏览器本地，清理站点数据或换浏览器后不能恢复，不提供云同步。
- 保留了本轮测试项目与未提交测试草稿，未删除既有用户数据。
