# 账号体系本地验收记录

验收日期：2026-10-08。前端 http://127.0.0.1:5175，后端 8082。使用独立 `example.test` 账号和测试项目；AI 为 Mock，邮件为开发捕获，没有真实 SMTP 投递、真实 AI 调用或上线部署。浏览器通过 Playwright MCP 实际操作，接口隔离和异常边界另由 Spring 集成测试验证。

## 验收结果

| 场景 | 实际结果与证据 |
| --- | --- |
| 注册、验证、登录、刷新、退出 | 浏览器完成待验证注册、打开捕获邮件、确认验证、登录与刷新；退出后回到匿名状态。见 register-pending.jpg、profile.jpg。 |
| 重复字段、错误密码、过期/重复凭据 | 服务端集成测试覆盖大小写归一、重复用户名/邮箱、未验证登录、错误密码、过期和重复使用、重发失效旧凭据。 |
| 找回和修改密码 | 独立测试账号通过浏览器完成修改和捕获邮件重置，第二标签页旧会话失效；测试覆盖全部会话失效。见 reset-success.jpg。 |
| 匿名额度 | 浏览器成功生成三份报告后下一次被限制，已有项目与草稿保留。服务端模拟正常 AI 失败并确认不扣成功额度。见 anonymous-quota.jpg。3 次为暂定配置。 |
| 匿名迁移 | 浏览器先拒绝，账号列表保持独立；再确认迁移整个三版本项目及来源草稿。测试覆盖重复提交、收据和项目版本完整性。见 migration-confirm.jpg、migrated-draft.jpg。 |
| 账号隔离 | 账号 B 直接打开 A 报告得到一致不存在提示；集成测试覆盖项目、报告、历史、任务包、版本创建、重命名/删除及伪造请求头。见 account-isolation.jpg。 |
| 旧版本迭代 | 浏览器从 V1 生成最新 V4，父报告仍为 V1；集成测试检查父子关联及并发版本编号。 |
| 草稿与返回 | 匿名与迁移草稿刷新后恢复 Idea、视角、语气；提交成功清理；退出后账号草稿清除，重新登录不恢复退出前标记；版本对比到报告可返回，旧报告标明最新 V4。见 old-report.jpg。 |
| 侧边栏 | 浏览器搜索、重命名、确认删除独立可删除测试项目、同步标题与列表、当前项目高亮通过。每页 20 项及未加载项目搜索由服务端测试覆盖。见 desktop-project.jpg、delete-confirm.jpg。 |
| 桌面和移动 | 实测桌面 1440px 与移动 390px；移动抽屉打开、进入项目后关闭、工作台内容排列正常。见 mobile-sidebar.jpg、mobile-project.jpg。 |
| 多标签页 | 浏览器验证退出、密码修改及账号切换后另一标签页同步更新；后退访问上一账号项目无法读取。 |
| 正式邮件未配置 | prod 集成测试实际调用注册接口，返回 500 与邮件未配置提示；正式模式不允许 capture，不假报发送成功。未做真实邮件收件验证。 |

报告附加操作：浏览器验证复制完整报告的成功反馈、开发任务包内容和产品体检卡显示。最终 Markdown/PNG 下载落盘未完成验证，不将按钮可见视为下载成功。

## 限制与上线前事项

旧 `X-Session-Id` 没有可信所有权证明，原数据和本地草稿保留，但无法安全自动认领，需要管理员确认归属后处理。真实 SMTP、AI、HTTPS Cookie/TLS、反向代理、分布式会话、限流高负载未验证；单实例会话在后端重启时失效。匿名基础限流不能完全防止清 Cookie 或换 IP 绕过。

迁移步骤、配置示例和上线前邮件待配置项见 [ACCOUNT_SETUP.md](../ACCOUNT_SETUP.md)。现有用户数据未删除，本轮仅软删除明确标记的独立测试项目。
