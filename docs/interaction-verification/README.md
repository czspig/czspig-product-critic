# 三处交互调整验收

本轮仅修改前端，保持既有设计、草稿及版本业务逻辑，未部署。

- 新建评审：侧边栏明确点击发出一次动画请求，标题每字 100ms；其他更新不会触发。隐藏完整文字预留标题高度，可访问标题始终完整；启用减少动态效果时直接显示完整标题。卸载时清理计时器。
- 版本对比：删除左侧固定链接“项目工作台”（/projects/:groupId），保留右侧来源返回入口。无来源时返回工作台，有有效报告来源时返回对应版本报告。
- 项目工作台：桌面操作同一行右对齐，8px 间距、40px 高度、文字不换行；窄桌面减少按钮内边距，移动端纵向排列。

## 实际验证

使用 Playwright MCP、独立测试账号和 Mock AI 项目验证：

- 点击新建后读取到中间文字“把产品”“把产”，最终展示完整原标题；再次点击仍保留已输入的 45 字内容。
- 相同输入与侧边栏状态下，动画初期及结束的标题高度均为 60.475px，输入框顶端位置均为 561.875px。输入及收起/展开侧边栏没有触发新的标题播放。
- 1440px 桌面三个操作 y 坐标一致，高度均为 40px；768px 窄桌面操作仍同一行并位于内容区域内。
- 版本页只保留一个顶部返回入口；返回工作台可用。从报告进入版本页时，保留入口为“返回 V1 报告”，实际返回正确报告。
- 390px 移动工作台三个按钮高度均为 40px，文档宽度 375px 小于视口 390px，无横向溢出。
- 前端 TypeScript 检查与生产构建通过。减少动态效果分支已实现，未实际切换系统偏好验收；本轮没有录屏，提供动画中途截图。
